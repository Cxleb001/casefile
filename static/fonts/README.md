# Fonts

Served with the app (Streamlit static serving) so the analyst view looks the same offline. Subset to Latin and
converted to WOFF2 from the files in [google/fonts](https://github.com/google/fonts). All three are under the SIL Open
Font License 1.1 (the OFL-*.txt files here).

| File | Family | Use |
| --- | --- | --- |
| PublicSans.woff2 | Public Sans (variable weight) | body text |
| SourceSerif4.woff2 | Source Serif 4 (variable) | headings, the decision headline and stamp |
| IBMPlexMono.woff2 | IBM Plex Mono Regular | SQL, account and transaction ids |
